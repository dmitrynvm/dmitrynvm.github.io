Retrieval from a customer's own record

A patent team kept missing prior art that keyword search could not reach. Hybrid retrieval — vector plus keyword — over PostgreSQL with an LLM re-ranking pass, answering strictly from their own corpus. From feasibility prototype to delivered product.

Concurrency failure that was not a capacity limit

Silo AI at AMD · client: AWS

An 8-bit quantized MiniMax 2.5 fell over whenever long-lived agent sessions overlapped. Everyone read it as a capacity limit, and the default answer was more GPUs. Tracing through the serving stack showed memory-allocation behaviour under concurrency instead — so the fix was allocation strategy and runtime configuration, on the hardware already bought. Concurrency then went into the benchmark harness so the same class of failure is caught before a customer meets it.
